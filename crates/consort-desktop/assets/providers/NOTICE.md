# Provider logos

These SVG files come from Lobe Icons (`@lobehub/icons-static-svg` 1.101.0, MIT license, https://github.com/lobehub/lobe-icons). The marks belong to their owners: Claude Code (Anthropic), Codex (OpenAI), Gemini CLI (Google) and OpenCode (Anomaly). Consort uses them only to name the provider that an account belongs to.

Logos of agents from the ACP registry are not stored here. The app loads them from the `icon` URL of each registry entry.

`claude-code.svg` and `gemini-cli.svg` have `width="48" height="48"` in place of `1em`. GPUI draws a full-color SVG as an image at its own size, so a larger size keeps the logo sharp at 18 px on a Retina screen. The paths are not changed.
